# The Friends Fan Test 🛋️🦞

An interactive, mobile-first web trivia game built for true *Friends* fans. Test your knowledge across 10 unique mini-game categories to determine your ultimate Friends fan level!

https://friends.prajapatimehul2610.workers.dev

---

## ✨ Features

- **10 Unique Interactive Mini-Games**:
  1. 💬 **Who Said It?**: Match famous quotes to the right character.
  2. 🚪 **Apartment Memory**: Memorize Monica & Chandler's apartments and spot what's missing.
  3. ⛲ **Complete The Scene**: Place iconic props into classic scenes (Opening fountain umbrellas, Thanksgiving turkey head).
  4. 🚪 **Who Would Do It?**: Guess which character would get into bizarre situations.
  5. 🔍 **Episode Detective**: Solve episode cases with progressive notebook clues.
  6. 🦞 **Relationship Puzzle**: Connect iconic couples and famous exes.
  7. 🛋️ **What Happened Next?**: Relive classic cliffhangers (*PIVOT!*, Ross's spray tan).
  8. ☕ **Central Perk Memory**: Remember where characters were standing in Central Perk.
  9. 🔊 **Sound Memory**: Identify iconic voice lines (*"OH MY GOD!"*, *"HOW YOU DOIN'?"*, *"I KNOW!"*, *"PIVOT!"*).
  10. 🏆 **Ultimate Fan Challenge**: A 15-second final boss scavenger hunt for hidden items (Geller Cup, Gladys, Hugsy).

- **🔒 "Lock It In?" Suspense Mechanic**: High-stakes moments where you can confirm or change your answer.
- **🎵 Nostalgic Audio**: Ambient background theme with automatic ducking during voice clips.
- **📊 Detailed Fan Ratings**: Dynamic scoring, category breakdown ratings (0–10), and a full missed-questions review.
- **🔁 Dynamic Sessions**: Automatic difficulty balancing and recent-question rotation so every playthrough feels fresh.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/mehulprajapati2610/friends.git

# Navigate to project directory
cd friends

# Install dependencies
npm install
```

### Running Locally
```bash
npm run dev
```
Open **http://localhost:5173/** in your browser. For the best experience, toggle mobile device emulation in DevTools (**390 × 844** / iPhone).

### Building for Production
```bash
npm run build
```
